1. Aprèn frases, no només paraules

Una frase curta que diries de debò («Ens pots fer una foto?») t’ensenya vocabulari, gramàtica i ordre de les paraules alhora, i la pots fer servir el mateix dia. Reserva les paraules soltes per a les coses que assenyalaràs.

2. Fes que cada targeta sigui petita

Una frase o una estructura per targeta. Si una targeta et sembla llarga, divideix-la. Les targetes petites es repassen més de pressa i es diuen més fàcilment en veu alta.

3. Afegeix context quan una paraula és ambigua

Quan una paraula té diversos significats, afegeix-hi una nota curta o un exemple per recordar el correcte. A Flippin, les notes apareixen a la targeta, sota la frase.

4. Etiqueta per temes

Etiquetes com viatges, menjar o feina et permeten estudiar en sessions centrades. Flippin permet fins a cinc etiquetes per targeta, i pots filtrar la baralla per qualsevol d’elles.

5. Fes servir imatges i emoji per recordar

Una imatge o un emoji t’ajuda a recordar el significat més de pressa, sobretot amb noms concrets. A Flippin, les imatges a les targetes i els suggeriments d’emoji amb IA formen part de Premium.

6. Repassa una mica cada dia

La constància guanya a la intensitat. Cinc minuts al dia mantenen viva la ratxa i fan avançar l’objectiu setmanal. Repassa les targetes pendents de Flippin comença per les targetes pendents, després els errors i després les noves, i cada resposta programa el proper repàs de la targeta d’aquí a uns quants dies o unes quantes setmanes.
